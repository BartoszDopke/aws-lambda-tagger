# AWS Lambda Tagger
Event-based AWS Lambda function automatically tagging supported resources

## Pre-requisities

- An AWS account
- Set of AWS credentials
- AWS Config enabled on your account

## How to build it

```terraform
terraform init
terraform plan
terraform apply -auto-approve
```

## How to destroy it

```terraform
terraform destroy -auto-approve
```
